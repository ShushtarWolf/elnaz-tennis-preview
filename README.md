# Elnaz Khanbeygi: website preview

Static demo build of the public site (GitHub Pages). Booking runs in **demo mode**: example time slots, and bookings are kept only in your own browser (localStorage), never sent anywhere. `/admin-demo/` is a click-through DEMO of the admin & finance panel with fictional data (in-memory, resets on reload, no backend). The real site, booking backend and admin panel live in a private repository.
